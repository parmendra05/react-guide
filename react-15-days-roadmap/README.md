# React 15-Day Roadmap

## How to Use
1. Open `TRACKING.md` to see your overall progress
2. Go into each `day-XX` folder and open `notes.md`
3. Follow the topics, complete the practice tasks
4. Update your status and score in `TRACKING.md` daily

---

## Daily Routine (3-4 hours)
| Time | Activity |
|------|----------|
| 30 min | Read the notes.md for the day |
| 2 hrs | Code the practice tasks |
| 30 min | Review & write your own notes |
| 30 min | Update TRACKING.md score |

---

## Rules
- Code every day, no skipping
- Always do the practice tasks, don't just read
- Score yourself honestly in TRACKING.md
- If score < 6, revisit before moving on

## Goal
Be React job-ready in 15 days 🚀
